# CloudCode Landing

CloudCode es una landing page moderna y profesional diseñada para presentar servicios tecnológicos a empresas que buscan mejorar su presencia digital, automatizar procesos o desarrollar productos digitales.

El proyecto funciona como sitio informativo y comercial, con una estructura clara para comunicar la propuesta de valor, mostrar servicios, presentar casos de uso y facilitar el contacto con posibles clientes.

## Tecnologias

- HTML5 semantico
- CSS3 (variables, grid/flex, media queries)
- JavaScript vanilla
- i18n con archivos JSON (`es` y `en`)
- Three.js para fondo visual del hero

## Secciones del sitio

### Inicio

Presenta la marca CloudCode y su propuesta principal: crear soluciones digitales para empresas que buscan destacar mediante software, diseño e inteligencia artificial.

### Servicios

Describe los servicios principales:

- Desarrollo web
- Desarrollo móvil
- Soluciones de IA

Cada servicio incluye una explicación breve y beneficios específicos.

### Nosotros

Incluye una descripción general de la empresa, misión y visión, reforzando el enfoque en transformación digital y soluciones escalables.

### Portafolio

Muestra proyectos demostrativos, como:

- Tienda online de alto rendimiento
- Sistema de control operativo
- Panel de métricas y reportes

Estos proyectos funcionan como ejemplos de soluciones que CloudCode puede desarrollar.

### Contacto

Incluye llamadas a la acción para enviar correo o contactar por WhatsApp.
